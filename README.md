# 快搜图 QuickPic 🔍

一个纯前端、单文件的搜图网站。输入关键词即可搜索图片，支持瀑布流浏览、大图预览和一键下载。

整个网站只有一个 `index.html`，没有任何依赖、不需要构建、不需要后端——双击打开就能用。

## 功能

- 🔍 关键词搜索（支持中文 / 英文）
- 🖼️ 瀑布流展示 + 图片懒加载
- 👆 点击看大图，键盘 `←` `→` 切换，`Esc` 关闭
- ⬇️ 一键下载当前图片（浏览器限制时自动回退为新标签页打开）
- 🏷️ 热门关键词快捷标签
- 📚 三个图源可切换：
  | 图源 | 特点 |
  |------|------|
  | 360图片 | 国内网络直连，中文搜索友好（默认） |
  | Openverse | 聚合 CC 授权开放图库，图片可自由使用 |
  | 维基共享 | Wikimedia Commons，开放授权 |

## 使用

**方式一：本地直接打开**

下载 `index.html`，双击用浏览器打开即可（搜索时需要联网）。

**方式二：在线地址**

已部署的在线版本：<https://af2ec66460104c4e88d4e32905b58c12.app.workbuddy.host>

**方式三：GitHub Pages（可选）**

本仓库已开启即用的静态页面，可在仓库 Settings → Pages 中将 Branch 设为 `main`，即可通过 `https://gaowen0303.github.io/image-search-site/` 访问。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖，零构建
- 360图片接口通过 JSONP（动态 `<script>` 标签）调用，绕开浏览器跨域限制，`file://` 本地打开也能搜索
- Openverse / Wikimedia Commons 接口通过 `fetch` 调用（在部分网络环境下可能无法直连，此时切换 360 图源即可）
- 图片下载使用 Blob + `URL.createObjectURL` 实现
